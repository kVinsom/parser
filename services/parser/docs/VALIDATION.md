Доповнення після реалізації QA: набір розширено до **146 автотестів**; додано
повторювані локальні й живі HTTP-бенчмарки, пороги p95 та JSON/Markdown/JUnit-звіти.

Команди, методика й результати — [BENCHMARKS.md](BENCHMARKS.md).

## Локальні відтворювані перевірки

- **107 тестів пройшли** на Windows, Python 3.12.14.
- **Ті самі 107 тестів пройшли** в тимчасовому Linux-контейнері Python 3.13.15.
  Папка проєкту була підключена лише для читання; зміни gateway не потрібні.
- Ruff перевіряє код, тести й інструменти. Залежності й генерація protobuf
  встановлені/виконані реально, з наявного `access.proto`.
- У тестах перевіряються DTO, усі gateway outcome, транспортні статуси,
  реальний локальний `grpc.aio` сервер/клієнт, HTTP, 32-МіБ транспортний ліміт
  у конфігурації, бюджет timeout+15, повторне використання/закриття каналу,
  OR-альтернативи, unknown/unsupported, Decimal, namespace, дублікати,
  пошкоджені картки, непідтверджена порожнеча, редиректи, скасування й місткість.
- Два попередження deprecation походять із Starlette TestClient/httpx та
  anyio BlockingPortal; помилок або пропущених тестів немає.
- Перевірка залежностей `pip check` пройшла; Ruff lint і перевірка форматування
  пройшли. Додатково перевірено безпечну відмову для надмірної вкладеності JSON
  та відповідність OpenAPI вимозі десяткових рядків для сум.

Ці тести не звертаються до Vinted. HTTP/gRPC помилки в них створюються локально,
а мутації HTML позначені як синтетичні. Реальні fixtures та контрольні суми —
[PROVENANCE.md](../tests/fixtures/PROVENANCE.md) і `tests/fixtures/manifest.json`.

О **10:26 UTC** виконано окремий шлях **реальний HTTP/Uvicorn → parser → gRPC →

residual, текст `nike` — як applied. PL через той самий HTTP API повернув 422.
Звіт: `.artifacts/http-smoke.json`. Тимчасовий HTTP-процес після перевірки завершено.

Це п'ять контрольних запитів, не навантажувальний тест. Надійність 24/7,
60 запитів/хв, реальна CAPTCHA/429, порожній каталог і остання сторінка
цими запусками **не доведені**. Обробка їхніх статусів перевірена локально;
порожнеча й кінець каталогу залишаються явними прогалинами.
