# Доступ до джерел оголошень

[README сервісу](../README.md) · [Регіони](../../../docs/REGIONS.md)

Стек: FastAPI, curl_cffi, обраний сервіс Byparr в окремому контейнері та зовнішні проксі користувача. Власна браузерна автоматизація через Playwright/Chromium можлива за потреби адаптера. FlareSolverr — резервна необов'язкова альтернатива. Порядок підключення Byparr описано в [BYPARR.md](BYPARR.md).

Вхід: source_id, регіон і дозволений запит каталогу. Вихід: відповідь джерела та технічні метадані або структурована помилка. Адаптер доступу вибирається за source_id з реєстру; у першій реалізації доступний тільки Vinted. Інші сайти можуть використовувати власні HTTP/API/браузерні стратегії за правилами [SOURCES.md](../../../docs/SOURCES.md).

- Усі запити до підключених сайтів проходять через gateway. Парсер не володіє паролями проксі. Домени, шляхи, редиректи та спосіб доступу перевіряються в контексті конкретного джерела.
- Для звичайних запитів використовуються асинхронний HTTP-клієнт і повторне використання з'єднань.
- Для операцій, які потребують браузерного сервісу обходу, gateway викликає Byparr і обмежує кількість одночасних операцій. Життєвим циклом браузера керує Byparr; наявність постійного пулу або повторне використання браузера між запитами не припускається.
- Сесії ізольовані за source_id, регіоном, проксі та профілем клієнта. Зберігаються cookies, строк придатності й стан сесії; cookies різних сайтів не змішуються.
- Налаштовуються гранична кількість паралельних запитів, таймаути й повторні спроби для кожного сайту/регіону/проксі. Повторні помилки зменшують частоту запитів і тимчасово відключають несправний маршрут, не зупиняючи інші джерела.
- Відрізняються помилки проксі, обмеження частоти, антибот-перевірка, відсутність доступу та зміна формату відповіді.
- Помилка доступу не повертається як порожній список оголошень.
- Gateway приймає лише запити до дозволених доменів і шляхів, не працює як довільний публічний проксі.

Обраний Byparr має приймати виклики з потрібною користувачу частотою 60 запитів/хв без тарифного обмеження сервісу. Це не показник затримки та не підтвердження прийняття всіх запитів сайтом. Перевіряються окремо кількість надісланих викликів, завершених відповідей та фактично отриманих сторінок каталогу.

curl_cffi підтримує асинхронні запити і профілі TLS/HTTP браузерів; Playwright підтримує браузерні контексти та проксі. Ці можливості самі по собі не гарантують проходження антибот-захисту. [curl_cffi](https://curl-cffi.readthedocs.io/en/latest/), [Playwright](https://playwright.dev/python/docs/network).

Byparr обрано для реалізації, але його проходження захисту Vinted у всіх регіонах ще не підтверджено. Vinted офіційно використовує DataDome, тому перевірка має охоплювати фактичний захист каталогу, а не лише Cloudflare. [DataDome про Vinted](https://datadome.co/customers-stories/vinted-partners-with-datadome-to-stop-account-fraud-protect-millions-in-revenue/).

FlareSolverr залишається резервною альтернативою для оцінювання; його README описує обмеження CAPTCHA. Перенесення cookies між браузерним сервісом і HTTP-клієнтом потребує перевірки сумісності. [FlareSolverr](https://github.com/FlareSolverr/FlareSolverr), [FAQ curl_cffi](https://curl-cffi.readthedocs.io/en/latest/faq.html).
