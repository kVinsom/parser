# Підписки LITE / PRO / ULTRA

Модель доступу відповідає повідомленню «Купити підписку»
(`vpars_bot/subscription_payments.py`) та [PLAN_LIMITS.md](PLAN_LIMITS.md).
Без активної підписки пошук недоступний; безплатного тарифу немає.
Підписка належить користувачу, регіони Vinted не оплачуються окремо.

Меню показує тариф, строк і ціну. Квитанція передається на перевірку;
сама її відправка не активує доступ. Адміністратор видає підписку
зареєстрованому користувачу за перевіреним @username, тарифом і кількістю днів.
Права й отримувач перевіряються повторно в транзакції; повтор операції
не додає днів вдруге. Фактичні ID користувачів залишаються незмінними.

Право пошуку перевіряється при збереженні, Start, виконанні та доставці.
Прострочений тариф не продовжує працювати через затримку фонового очищення.
Недозволені пошуки переходять у `paused_limit`, параметри й історія зберігаються.
Поновлення підписки не запускає їх автоматично й не оживляє старі повідомлення.
Повний Stop діє також для адміністраторів.

Адмінроль надає безстроковий ULTRA. Після її відкликання застосовується
фактична підписка користувача. Зміна днів не змінює роль.
Ліміти й облік місячної квоти Autobuy: [PLAN_LIMITS.md](PLAN_LIMITS.md).
